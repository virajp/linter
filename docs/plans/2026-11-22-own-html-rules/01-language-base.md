## Edits

1. **`src/plugins/html/language/`** — port `lib/languages/` to TypeScript.
   Use our `@eslint/plugin-kit` 0.7.3; where its API differs from 0.4, adapt
   the call and report each as `DECIDED:`.
2. **`src/plugins/html/adapters/`, `constants/`, `data/`, `types/`,
   `utils/`** — port `lib/adapters/`, `lib/constants/`,
   `lib/data/entities.json` (as `entities.ts`: a script reads the upstream
   JSON and writes a module whose default export is the same object; never
   retype it; D11 d), `lib/types/` and
   `lib/rules/utils/` (including `template-literal`; not `capo.d.ts`, because
   `@rviscomi/capo.js` ships its own types; D12 b). Keep the behavior the same.
3. **`src/plugins/html/meta.ts`** — the name is `html`; use the same version
   source as `src/plugins/toml/meta.ts`.
4. **Header of each ported file** — the first line is
   `// Ported from @html-eslint/eslint-plugin v0.68.0 (MIT), <upstream path>.`
   (the path under `packages/eslint-plugin/`), `entities.ts` included.
5. **`THIRD_PARTY_NOTICES.md`** — append a section for
   `@html-eslint/eslint-plugin` 0.68.0: repository URL,
   `Copyright (c) 2020 YeonJuan`, and the full MIT text in a fenced `text`
   block, the same shape as the other sections.
6. **`tests/unit/plugins/html/helpers/rule-tester.ts`** — port
   `tests/rule-tester.js`. It takes the plugin object as a parameter and
   makes the HTML tester and the `"espree"` template tester as upstream does,
   without the `TEST_ESLINT_LEGACY_CONFIG` branch; keep the `parserOptions`
   remap of the language-mode tester (D12 a). It connects `RuleTester` to vitest
   for every HTML test
   (D11 e).
7. **`tests/unit/plugins/html/language/`** — port `tests/languages/*.test.js`
   to TypeScript, with the source header. Build the plugin object from
   `src/plugins/html/language/` directly. Leave out each case that needs a
   rule, and list each in `DECIDED:`; U6 adds them.

8. **`tests/unit/plugins/html/utils/template-literal.test.ts`** — port
   `tests/rules/utils/template-literal.test.js` (D11 c), with the source
   header.
