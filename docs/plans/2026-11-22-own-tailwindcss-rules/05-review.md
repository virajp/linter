# U5 — Review: the Tailwind plugin, its rules and the @eslint/css upgrade

## Scope

This review covers U1, U2, U3 and U4: the Tailwind syntax and helpers, the
18 ported rules with their tests, the plugin index, the switch of the `css`
preset, the removal of `@poupe/eslint-plugin-tailwindcss` and the upgrade of
`@eslint/css` to 2.0.1. It reviews the branch delta since the branch base, as
it is the first review unit of the plan. The change lands runnable code that
ships in the published package (D10).
